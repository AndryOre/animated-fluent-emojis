# Animated Fluent Emojis brand kit

The source of truth for the project's identity: decisions, voice, copy, tokens
and logo files. The name stays **Animated Fluent Emojis** everywhere. The brand
is applied as identity: mark, voice, palette and motion.

## Documents

- [`brief.md`](brief.md): audience, pains, cultural position, visual world,
  palette, logo, typography, what to avoid and closed decisions.
- [`competitors.md`](competitors.md): market research and positioning lessons.
- [`naming.md`](naming.md): how the name was decided, with the scoring.
- [`voice.md`](voice.md): voice guidelines, tone matrix and terminology.
- [`copy.md`](copy.md): README intro, features, `package.json` and GitHub copy.
- [`apply-spec.md`](apply-spec.md): where each brand decision lands in the
  repository, and what is still manual.

## Assets

- [`tokens.css`](tokens.css): design tokens as shadcn-style variables in oklch,
  light and dark. Primary is the Mint accent, and `--primary-text` is the darker
  ink for text and links on light grounds. `--destructive` and `--success` are
  shadcn's defaults, as the brand does not define them.
- [`logo/`](logo/): the Sticker mark (`mark.svg`, `mark-black.svg`,
  `mark-white.svg`, `mark-animated.svg`) and the horizontal lockups, with the
  wordmark outlined to paths. PNG marks at 16, 32, 48, 128 and 512 px are in
  [`logo/png/`](logo/png/).
- [`og/`](og/): `social-preview.png` (1280x640, for the GitHub repository
  settings) and `og.png` (1200x630, for a future landing page).
- [`brandbook/`](brandbook/index.html): a standalone HTML brand book. Its fonts
  live in [`brandbook/fonts/`](brandbook/fonts/) with their license in
  [`OFL.md`](brandbook/fonts/OFL.md).

There is no halo mark, YouTube art, store tiles or app icons: the project has no
dark-only surface, channel or store listing. The Claude Design canvas that
produced the palette, logo and type choices is not versioned.

## Regenerating assets

The PNG marks, the social preview, the Open Graph image and the README covers
are derived from the SVGs in [`logo/`](logo/). After changing a source SVG or
the copy in [`tools/export.mjs`](tools/export.mjs), run `bun run brand:export`
(needs Chromium: `bunx playwright install chromium`). The script embeds the
fonts from [`brandbook/fonts/`](brandbook/fonts/), so output does not depend on
fonts installed on the host. It throws if an image misses its exact size or byte
budget: 1 MB for the social preview (GitHub's limit), 300 KB for the Open Graph
image and for each cover.

The lockups come from the Figtree variable font at weight 800, tracked at
-0.03em. They are not regenerated by the script: rebuild them with a font tool
(`fontTools` and `uharfbuzz` were used) if the wordmark changes.
