# AGENTS.md

Instructions for coding agents working in the asset pipeline. The root
[`AGENTS.md`](../../AGENTS.md) rules apply here too.

## What this workspace is

A private workspace (`@animated-fluent-emojis/assets`) that generates the
manifest and sprites, and the files site, published to Cloudflare Pages by
`sync-assets.yml`. It depends on `sharp` and `yaml` itself; the library does
not.

## Rules

- The manifest and sprites are generated by this workspace and published to
  Cloudflare Pages by `sync-assets.yml`; never commit sprites, `dist-assets/` or
  `dist-files/`:
  [`docs/architecture.md#asset-site`](../../docs/architecture.md#asset-site).
- Outputs default to this directory (`dist-assets/`, `dist-files/`,
  `.cache/assets`) whatever the working directory. The generated emoji-id file
  and the emoji lists are written to the library and `docs/`;
  `public-slugs.json` stays here.
- Run the pipeline through the root scripts (`bun run assets:detect`,
  `assets:build`, `assets:verify-live`, `assets:lists`, `assets:files`), which
  call this workspace's scripts.
- Import the library's manifest types only as type-only relative imports of
  `../../packages/animated-fluent-emojis/src/utils/types.js`; never add a public
  export to the library for the pipeline. The
  `animated-fluent-emojis: workspace:*` devDependency exists so Turborepo hashes
  that edge.
- Tests run in a `node` Vitest project (`bun run test` from the root runs them
  through turbo). Every source module here needs a test or an exemption in
  `scripts/coverage-manifest.test.ts`.
